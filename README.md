# Learning-JS-TS

A learning repository for JavaScript, TypeScript, and their ecosystems.

## Next.js authentication and email

The authentication learning project now lives directly in **[Next-JS/Auth](./Next-JS/Auth)**. It is self-contained in this repository, not a submodule or a dependency on the former Learn-Auth-Next repository.

It covers signup, email verification and resending links, login, HTTP-only cookie sessions, a protected profile, password recovery, and sign-out with session invalidation.

See the **[setup and learning guide](./Next-JS/Auth/README.md)** to run it with MongoDB and SMTP.

The other learning projects remain in their existing directories: JavaScript, Typescript, React-JS, Express-JS, Fastify, SQL, Prisma, Drizzle, Tanstack, and Cypress.
